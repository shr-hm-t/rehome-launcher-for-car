# Rehome: Launcher for Car

<p align="center"><img src="assets/screenshot-home.png" width="49%"> <img src="assets/screenshot-bar.png" width="49%"></p>

Free apps for Android car head units. Tested on one unit only, so yours may differ. Made with a lot of help from AI.

**Download both:** [Releases](../../releases/latest)

| App | What it is |
| --- | --- |
| **Rehome: Go** (`Rehome-Go.apk`) | Home app that opens Google Maps. Adds a corner frame and one pill with 3 buttons: 360, Maps, radio/YouTube. Includes **Boot Pack**. |
| **Rehome 1.7** (`Rehome.apk`) | Full launcher: offline map, contacts bar, room for the unit's own 360 picture-in-picture. |

## Go in 4 steps

1. Install, open it, allow **display over other apps**.
2. Set it as the Home app, then restart the unit.
3. Press Home: Maps opens. Tap a button to open that app.
4. **Hold** a button for the extra action:
   - **360**: opens the 360 player ([car360-player](https://github.com/bv-ack/car360-player))
   - **Maps**: move, resize and set transparency of the buttons
   - **Radio / YouTube**: opens the other one (YouTube opens in Brave)

Optional permissions: **location** (speed light, 360 when creeping along slowly) and **usage access** (third button switches radio/YouTube). Go works without them.

## Boot Pack

Open **Rehome: Boot Pack**, pick your emblem, press **Make the boot pack**. Files appear in `Download/Rehome`: `bkg.png`, `logo.png`, `logo.bmp`, `bootanimation.zip`, `keyboard.png`. You install the boot files on the unit yourself. If it fails, force-stop Rehome: Go first.

## Rehome 1.7

Press Home, choose Rehome, follow the welcome screen. Settings: hold the 360 icon.
